# Maestro — interactive classroom demo

Try it: https://dstiv-ai.github.io/maestro-demo/

Designed and built by Dimitrios Stivaktas.

A two-minute demonstration of lesson cards, the Student Thinking Grid and teacher-reviewed feedback. All learners, answers and marks are fictional. AI suggestions are prerecorded examples. This static demo has no sign-in, backend, paid AI calls or cross-device synchronisation. Changes last only for the current tab and reset on reload.

This repository contains only generated static demo files; it does not contain the original app source or configuration.
